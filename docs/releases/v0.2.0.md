# llm-gateway v0.2.0

**中文** | [English](v0.2.0.en.md)

## 安装

[安装教程](../../integrations/dsh-agent-gateway/README.md) · [下载安装包](https://github.com/CalvinL10/llm-gateway/releases/tag/v0.2.0)

下载 Release 附件中的 **llm-gateway-dsh-agent-gateway-0.2.0.tgz**，不要把自动生成的 Source code 压缩包当作插件安装包。

首次安装默认关闭。按安装教程配置授权工作区和策略后启用，再启动已有 DSH Web；安装不会选择账号或启动任务。

## 本次交付

- 原生 DSH bundle 安装和移除，preset 随包加载，不依赖历史 Home 或 release 路径。
- `./plugin` 入口与普通会话共存；原默认入口仍保持专用宿主的严格行为。
- 保留任务 API、页面、主子模型选择、委派、共享额度、原生审批、取消与继续。
- Docker 执行器为显式可选依赖，仅作用于网关 preset；没有不受隔离的宿主 shell 回退。
- 中断任务重启后变为 `unknown`，不会自动重放。

## 实际验证

同一发布包通过原生命令接入两个独立 Home，复用已有运行时。检查覆盖默认禁用安装、启用后的页面和 API、普通会话共存、认证及来源和 Host 拒绝、数据与偏好隔离、结果、委派、额度、审批、取消、继续、中断重启不重放、移除后宿主可用，以及重装保留数据。

使用本地可控模型响应；**真实模型调用为零，没有执行真实 Docker 开发命令**，没有重跑历史比较实验。

## 兼容与限制

- 本轮仅验收 Windows、`127.0.0.1`、DSH Web。
- 实测 CLI **0.1.5-rc.1** / 服务包 **0.1.5-rc.2** **含既有本地修改**；版本号相同不代表未经修改的上游安装兼容。不附带运行时。
- 安装包只含插件运行代码、preset 和双语教程，不含测试、日志、账号、凭据、历史 Home 或实验资料。
- 验证证明接入和控制流程，不代表完整真实模型开发验收或费用收益。
- 本地旧启动辅助在最终重装后曾出现一次启动超时，清理该进程后正常重试成功，根因尚未定位；该辅助不在插件包内，也不是安装前提。
