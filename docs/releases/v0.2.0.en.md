## Installation

[Installation guide](../../integrations/dsh-agent-gateway/README.en.md) · [Download package](https://github.com/CalvinL10/llm-gateway/releases/tag/v0.2.0)

Download **llm-gateway-dsh-agent-gateway-0.2.0.tgz** from the release assets, not the auto-generated Source code archives.

```powershell
$env:DSH_HOME = 'F:\my-dsh-home'
dsh plugin --profile web add F:\packages\llm-gateway-dsh-agent-gateway-0.2.0.tgz --config.auto-install-peers=false
```

Configure authorized workspaces and policy before enabling the plugin; then start the existing DSH Web host. See the guides for complete configuration and removal instructions.

## Included

- Native DSH bundle installation/removal; package-relative presets; no historical Home or release paths.
- Coexisting `./plugin` entry, with strict dedicated behavior retained at the original default entry.
- Existing task API/UI, model selection, delegation, shared limits, approvals, cancel and continue.
- Explicit optional Docker executor scoped to gateway presets, with no unsafe host-shell fallback.
- Interrupted tasks become `unknown`; restarting never automatically replays them.

## Actual checks

The exact release package was installed through native DSH commands in two independent Homes using the same existing runtime. Checks covered disabled-first installation, enabled page/API, ordinary-session coexistence, authentication/origin/Host rejection, isolated data/preferences, result/delegation/limit/approval/cancel/continue, interrupted restart without replay, removal with the host still usable, and retained data after reinstall.

**Zero real model calls; no real Docker development commands were run. Historical comparison experiments were not rerun.**

## Compatibility and limitations

- Windows, `127.0.0.1`, DSH Web only for this acceptance.
- Tested CLI **0.1.5-rc.1** / service packages **0.1.5-rc.2** include **existing local modifications**. Matching upstream version numbers alone do not guarantee compatibility. The runtime is not included.
- The package includes runtime plugin code, presets and bilingual guides only: no tests, logs, accounts, credentials, historical Homes or experimental evidence.
- These results establish integration/control flow, not complete real-model development acceptance or cost savings.
- The local legacy launcher had one startup timeout during final reinstall; its process was cleaned up and a normal retry succeeded. That timeout's root cause remains undetermined. The legacy launcher is not part of this plugin package.
