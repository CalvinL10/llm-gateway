## What Is New Since v0.2.0

- **OTel Causal Trace Tree & Deterministic Policy Sensor (Slice 2-Lite)**: `report.js` emits `gateway-otel-trace-v1` (`task -> attempt -> llm -> tool -> approval / denial / sensor`) and `gateway-policy-sensor-v1` (`L1_AUTO_PASS` / `L2_AUTO_WARNING` / `L3_HUMAN_REQUIRED`). `index.js` collects read-only Git Baseline/Delta telemetry (isolated from parent repositories and tolerant of pre-existing dirty entries) to catch test tampering and security/contract drift. `panel.js` surfaces the read-only sensor gate and finding codes in `#validation` without relaxing `not-established` / `unverified` notices.
- **Online Token Budget Cap & Read-Only Prefix-Cache Telemetry (Slice 1-Lite)**:
  - `policy` adds optional tree-level `maxTotalTokens`, soft warning ratio `tokenWarningRatio` (default `0.8`), and deployment allowlists `authorizedTaskMaxTotalTokens` / `authorizedContinuationTokenIncrements`. Limits are checked at stream admission against observed cumulative usage (an already-admitted in-flight call may overshoot and settle if no subsequent admission is requested; subsequent admissions trigger `TASK_TOKEN_LIMIT`). Results populate `report.tokenBudget`.
  - `report.observations.prefixCache` and `auditExport` expose `gateway-prefix-cache-v1`, tracking `cacheReadTokens / (inputTokens + cacheReadTokens)` per `(sessionId, provider, model, source)` over reporting calls and flagging `PREFIX_CACHE_DROP` ratio drops. Missing `usage` or omitted `cacheReadTokens` (including adapters that omit `0` on a full cache miss) remains `missing` / `unreported` and is never zero-filled; **no online USD estimation or automatic model downgrade routing is claimed** (offline accounting remains in `ops/cost-report.mjs`).
  - `panel.js` appends read-only token budget and prefix-cache summaries only when enabled/observable, leaving inactive tasks unchanged.
- **Win32 Transient Storage-Lock Hardening & Smoke Diagnostics**: `TaskLedger` applies bounded exponential-backoff retries exclusively to transient Windows `EBUSY` and non-`open` `EPERM` storage locks inside serialized `create`/`edit` boundaries (`edit` wraps exhausted retries in `TaskStorageError` while `create` rethrows the underlying storage error; `EACCES` and non-lock errors are never retried, preserving Persist-before-Admit and fail-closed semantics). `smoke/web-smoke.mjs` prints token-redacted task diagnostics on assertion failures.
- **Bilingual Documentation & Windows CI**: Added bilingual docs and `.github/workflows/verify.yml` running doc contracts, exact 22-file package boundary checks, serialized core/ops regression tests, and zero-model HTTP/SSE smoke on `windows-latest`.
