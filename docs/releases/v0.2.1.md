## 相对 v0.2.0 的增量交付

- **OTel 因果血缘树与确定性 Policy Sensor（Slice 2-Lite）**：`report.js` 输出 `gateway-otel-trace-v1`（`task -> attempt -> llm -> tool -> approval / denial / sensor`）与 `gateway-policy-sensor-v1`（`L1_AUTO_PASS` / `L2_AUTO_WARNING` / `L3_HUMAN_REQUIRED`）；`index.js` 在不穿透父仓 `.git` 且隔离预存在脏工作区的前提下采集只读 Git Baseline/Delta 进行测试与契约防篡改审计；`panel.js` 在验证区块追加只读传感器门禁及原因码提示，不削弱 `未建立 / 未验收` 提示。
- **在线 Token 额度硬治理与只读 Prefix-Cache 观测（Slice 1-Lite）**：
  - `policy` 新增可选树级累计 Token 上限 `maxTotalTokens`、软告警阈值 `tokenWarningRatio`（默认 `0.8`），以及服务部署侧 `authorizedTaskMaxTotalTokens` / `authorizedContinuationTokenIncrements`。限额在流准入（admission）时按已观测累计用量校验并触发 `TASK_TOKEN_LIMIT` 熔断（已准入的在途调用仍可能单次超支并按原结果落盘，直到下一次准入被拒）；结果纳入 `report.tokenBudget`。
  - `report.observations.prefixCache` 与 `auditExport` 输出 `gateway-prefix-cache-v1`，按 `(sessionId, provider, model, source)` 分组统计 `cacheReadTokens / (inputTokens + cacheReadTokens)` 命中率并检出同源跨轮 `PREFIX_CACHE_DROP` 比率骤降告警。缺失 `usage` 或适配器省略 `cacheReadTokens`（包含上游完全未命中时省略 `0` 值字段的情况）均记为 `missing` / `unreported`，绝不补 `0`；**不提供在线美元估算或自动模型降级路由**（离线账目仍在 `ops/cost-report.mjs`）。
  - `panel.js` 在启用 Token 预算或存在可观测 Prefix-Cache 数据时于预算行补充只读摘要；未启用时保持原展示不变。
- **Windows 瞬态存储锁抗抖动与 Smoke 诊断加固**：在 `TaskLedger` 串行写盘边界仅针对 `win32` 的瞬态 `EBUSY` 与非 `open` 系统调用的 `EPERM` 增加有界指数退避重试（`edit` 重试耗尽仍抛出 `TaskStorageError`，`create` 透传底层存储错误，保持 `Persist-before-Admit` 与 fail-closed 语义；权限错误 `EACCES` 与非锁错误零重试）；`smoke/web-smoke.mjs` 在关键状态断言失败时输出脱敏后的任务现场 JSON 以便定位。
- **双语文档与 GitHub Actions Windows CI**：补齐中英双语仓库文档与 `.github/workflows/verify.yml`，在全新 `windows-latest` 环境自动校验文档链接、22 个发版文件边界、串行核心/运维回归与零模型 HTTP/SSE Smoke。

## 实际验证

- **全量串行回归与运维测试（31 个测试文件，0 fail / 0 skipped）**：覆盖原生包双 Home 安装共存与移除、安全边界、崩溃恢复不重放、`OTel Trace` 与 `Policy Sensor`（含 Git 隔离与防篡改）、Windows 瞬态锁重试、在线 `maxTotalTokens` 与 `prefixCache`、以及浏览器 UI。
- **零模型 HTTP/SSE Smoke 连续压测**：`smoke/web-smoke.mjs --http` 连续多次执行均返回 `AGENT_GATEWAY_PASS`（`realModelCalls: 0`）。
- **包清单与文档契约**：`npm pack --dry-run ./integrations/dsh-agent-gateway` 严格输出 **22 个运行/预设/文档文件**（不含测试、日志、账号、凭据、历史 Home 或实验目录），`docs/documentation.test.mjs` 与 `git diff --check` 全部通过。

## 兼容与限制

- 当前仅验收 **Windows、本机 `127.0.0.1` 回环、兼容 DSH Web**；不声称跨系统或公网多租户生产就绪。
- **零真实模型调用、未在自动化验证中执行真实 Docker 开发命令**；历史 `v0.2.0` 文档记录与 `v0.3.0-rc.1` 订阅预发线各自保持独立。
- `businessOutcome` 与 `validation` 仍保持 `unverified` / `not-established`，只读传感器和 Prefix-Cache 指标不能替代人工测试与业务验收。
