# v0.3.0-rc.1 — DSH 0.2.1-rc.3 候选版

**中文** | [English](v0.3.0-rc.1.en.md)

新增普通 DSH 对话中的 Codex / ChatGPT、Antigravity 和 Claude 订阅连接，
以及独立的主模型、默认子模型与单次子代理模型选择。DeepSeek 和其他 API
渠道继续可用，也可以与订阅渠道混用。安装不会自动登录或修改模型默认值。

## 安装

把以下 Release 附件的下载链接粘贴到 DSH「插件 → 添加插件」最上方输入框：

[llm-gateway-dsh-subscriptions-0.3.0-rc.1.tgz](https://github.com/CalvinL10/llm-gateway/releases/download/v0.3.0-rc.1/llm-gateway-dsh-subscriptions-0.3.0-rc.1.tgz)

按提示重启，再到「设置 → 订阅连接与模型设置」登录、刷新目录、保存选择，
然后新建普通对话。无需从插件任务页面发起对话。不要填写 GitHub 仓库首页，
不要安装自动生成的 Source code 压缩包。安装源可保持 npm 官方源。

本包名称是 `@llm-gateway/dsh-subscriptions`，版本是 `0.3.0-rc.1`，声明宿主
版本为 `0.2.1-rc.3`。采用原生 bundle、客户端设置槽、模型注册和配置编辑器。
单次子模型覆盖适用于原生 spawn 子代理；分叉和外部产品子代理沿用宿主配置。
保存的默认值及允许列表用于新会话，不改写已运行会话。

## 本次验证

环境：Windows、Node 24.15.0、原生 npm DSH 0.2.1-rc.3、独立测试 Home、
本机回环地址、无界面 Microsoft Edge。已核实本机安装的 DSH 桌面版和
desktop-host 包也标为 0.2.1-rc.3。以下共 14 项测试通过，无跳过。

- 用实际生成的 `.tgz` 通过原生插件管理器安装、移除及重新安装。
- 普通新会话、默认子模型、单次指定子模型、跨渠道主／子模型组合。
- 原生 API 适配器连接独立本地 HTTP 服务，作为主模型和子模型完成响应；
  卸载后 API 渠道仍可调用。
- 配置重启持久化；保存子模型不覆盖主模型；保留已有预设、权限和分叉配置。
- 未授权请求返回 401，外域设置写入返回 403，账号设置仅通过原生受保护路由。
- 三家原始适配器的受控协议测试，覆盖授权请求头与工具调用／结果往返。
- 浏览器实际加载插件、显示三家登录入口、保存主／子模型、创建普通新会话，
  没有客户端脚本异常。
- 通过桌面版自带的安装器、Electron Node 与 desktop-host，在独立的 Web
  测试 profile 中安装、启动插件并访问模型目录和三家账号状态接口；测试
  不打开桌面窗口。此项不覆盖实际桌面渲染器的通信和日常 profile。

测试程序位于 `integrations/dsh-subscriptions/test`。宿主和浏览器测试的运行
要求见该目录的使用说明；没有配置运行环境时会报告跳过，不代表通过。
